# Everything new in v1.2.0 (since v1.1.1)

This is the complete list. The release page carries a shorter summary.

Since v1.1.1:

- **No more black dot after tool names.** The Canvas tool name is a dropdown chip. A Page line is just the chip. Assignment, Assignment (Not Graded), Discussion and Quiz lines keep "; Link to settings tab" after it, because those tools have a settings tab. Older documents that still have the dot are recognized too.
- **Icons are dropdown chips too.** In the Course content Google Doc, each Blueprint icon (Attention, Audio, Computer, Document, Discussion, List, Looking Ahead, Policies, Reading, Schedule, Syllabus, Task, Tip, Upload, Video, Warning) is now a dropdown chip like the one in the template, with the right icon selected.
- **New: Clean course document.** A readable copy of the course without the Blueprint markup: modules as headings, a contents list at the top that jumps to each activity, and the real due and availability dates from Canvas. Under **Advanced options** you can choose whether each activity starts on a new page and whether the Canvas tool name (Page, Assignment, Discussion…) is shown under each title. It saves as a Google Doc, or as an `.html` file if you are not signed in to Google.
- **New: choose your course from a list.** Press **Choose from my courses** to pick from the courses where you are a teacher, TA or designer, on any Canvas site at an instructure.com address, instead of pasting an address. Master and template courses come first, you can search by name or code, and Blueprint courses are tagged, and each course shows your role by its Canvas name (for example Course Administrator, not just Teacher). Pasting a course address still works.
- **Better item pickers.** Each module has an **Everything in this module** box, you can choose the home page and syllabus on their own, and the list ends with a group, **Published content not in a module**, for published pages, assignments, discussions and classic quizzes that no module holds. Group headings are now pale-blue bars that stay in view as you scroll.
- **Easier to tell documents apart.** The course address and the time of the extraction appear under the title. Google Docs are named "[Course name] — Course Content Extraction" or "[Course name] — Clean Course Content Extraction".
- **Saved files.** Suggested file names include the course, for example `course_content_extraction_ecampus_demo.html`. Saved `.html` files open in a centered, padded column that is easier to read, and Save dialogs start in your Downloads folder.
- **Clearer Google sign-in.** The app checks your Google sign-in when it starts, says plainly whether you are signed in and where files will go, and explains problems in everyday words.
- **Plain-English Canvas errors.** When Canvas will not do something, the message now says what happened and what to do: a saved access code that no longer works, an account that is not allowed in the course, a course Canvas cannot find, Canvas asking the app to slow down, Canvas having trouble on its end, and no connection. Each has a **Show technical details** link with a **Copy details** button for whoever supports the app.
- **Fixed: "Insufficient Permission" when saving to Google Drive.** If Google signs you in but you did not tick the Drive box on its consent screen, the message now says so and tells you to sign out, sign in again and tick the box. Google sign-in messages use the same **Show technical details** link.
- **Who to contact.** Error messages that need help now name Greg Snow (gregsnow@boisestate.edu or extrasnow75@gmail.com) instead of "the person who supports this app".
- **Cancel a Google sign-in.** While the app waits for Google in your browser, a **Cancel sign-in** button lets you stop waiting instead of waiting out the three minutes. This helps when Google shows "Access blocked".
- **Asks before sending your Canvas token to another site.** The Boise State Canvas site is trusted. For any other Canvas address, a pop-up window asks once whether your token may be sent there.
- **Saved `.html` pages block scripts.** A page saved to your computer can no longer run a script that was left in a course page. Links in error messages open only the places the app sends you to.
- **Extractions to Google stop early** if your Google sign-in is missing or has expired, before any course content is read, so you do not lose a long run at the end.
- **Fixed: page breaks in the Clean course document.** The page-break choice did nothing in a Google Doc, because Google ignores the setting when it imports the page. The app now sets the breaks after the document is created: every module, the Home Page and the Syllabus start a page, and so does each activity when **Page breaks** is ticked.
- **Embedded videos now show up.** YouTube, Panopto, Vimeo and other embedded players used to disappear from Google Docs without a trace. In the Clean course document each one is a small video card: a "▶ VIDEO" label, the video's own title as a link, and the website beneath. In the Course content document it is a line that starts "Embed video:" with a link. For YouTube and Vimeo, the title comes from the service when the course did not name the video.
- **Broken links are highlighted in light red.** In both Google Docs, a link whose address cannot work as written is marked in light red: an empty address, a web address whose link is missing the "https://" at the start (such a link points to a page on the same site, not to the website), a mistyped one such as "htp://", and an embedded video with no usable address. The app also asks YouTube and Vimeo whether each video linked or embedded in the course still exists, sending only the video's public address, and marks the ones that have been deleted. A link whose destination is just an email address, with no "mailto:", does nothing when clicked, so it is written as plain text instead. Videos on services that need a login, such as Panopto, are not checked, and if YouTube or Vimeo cannot be reached the links are left as they are.
- **The Validate button shows where you are.** It is grey until the course address is complete, a blue Validate with "Not checked yet" beneath it when the address has not been looked up, "Checking…" while it is, and a green "Validated" once the course is found. A course chosen from the list is looked up for you, so it goes straight to green. If Canvas cannot load the course, the button says "Try again".
- **Fixed: two scroll bars** on the right side of the window. There is now one.
